Airline Flight Delay Prediction & Analysis

A team capstone from the Advanced Data Analysis Track at the National Telecommunication Institute. The question: using only what is known around departure, can we predict whether a flight arrives 15 or more minutes late? My responsibility covered modelling, evaluation and deployment. A complementary Power BI report explores the same data from a business-reporting angle.

About

How I work

I am a university student building a career around data. I like problems where the answer has to survive contact with reality — where a number is only useful if someone can act on it. That usually means doing the unglamorous parts properly: understanding the business question, cleaning the data honestly, and being explicit about what a model can and cannot see.

  1. 01

    Analyse

    Start from the question, not the dataset. Clean, profile and explore until the patterns are defensible — and say plainly when a signal is weak.

  2. 02

    Model

    Build and compare models against a success criterion set in advance. Choose for the cost of being wrong, not for the highest accuracy on a slide.

  3. 03

    Ship

    Put the result somewhere it can be used — an interactive app, a report, an automated workflow. Analysis that stays in a notebook changes nothing.
